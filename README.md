# MedMentor Backend

FastAPI backend for MedMentor — an AI learning companion for medical students.

## 🏁 How to Run

```bash
source venv/bin/activate
uvicorn app.main:app --reload
Navigate to: http://127.0.0.1:8000
```

🔐 Environment Variables
See .env.example for required secrets (OpenAI, TiDB, etc.)
